Minisforumが、ミニ PC「M2 Pro-358H」の注文受付を開始した。価格はセールで1,439ドル（通常1,799ドル）、欧州向けは1,519ユーロ（通常1,899ユーロ）。CESで初公開されてから8か月越しの発売になる。米国向けは9月下旬、欧州向けは9月初旬に香港から発送予定とされている。

## スペック

| 項目 | 内容 |
| --- | --- |
| CPU | Intel Core Ultra X7 358H（Panther Lake、Intel 18A、16コア16スレッド、最大4.8GHz） |
| TDP | パフォーマンスモード65W／バランス・クワイエットモード45W |
| GPU | Intel Arc B390（Xe3コア12基、最大2.5GHz） |
| メモリ | 32GB LPDDR5X（7,467 MT/s） |
| ストレージ | M.2 2280スロット3基、1基あたり最大8TBで計24TBまで |
| 通信 | 10GbE、2.5GbE、Wi-Fi 7、Bluetooth 6.0 |
| ポート | USB4（40Gbps）×3 |
| サイズ・重量 | 195×195×47.5mm、1.39kg |
| 電源 | 134.9W |
| 価格 | 1,439ドル（欧州1,519ユーロ）※いずれもセール価格 |

出典はNotebookcheckおよびMinisforum公式ストア。

## CES発表からの後退

MinisforumはCES 2026でM2 Proシリーズを発表した際、最上位にCore Ultra X9 388H、下位にCore Ultra 5 338Hを予定し、メモリも96GB・9,600 MT/sという構成を掲げていた。しかし今回実際に販売が始まったのはCore Ultra X7 358Hの単一構成のみで、メモリも32GB・7,467 MT/sに縮小されている。上位・下位モデルの扱いについて、参照した記事に続報の記載はない。発表時のスペックと発売時のスペックが一致するとは限らない、という典型例と言える。

## 日本から見るとどうか

**国内正規代理店は確認できていない。** 購入は米国向けのminisforum.com、欧州向けのminisforumpc.frからの海外発送が前提になる。Minisforumはこれまでもelitemini・M2 Air系など複数モデルが並行輸入や一部代理店経由で国内に入ってきているが、本機についての国内取り扱い情報は今のところ見当たらない。

**技適とPSE** — Wi-Fi 7とBluetooth 6.0を積むため、国内で無線機能を使うには技適が前提になる。また134.9W電源を使うデスクトップ機のため、国内で販売する場合はPSEの対象にもなる。いずれも本機について取得済みとの記載は確認できていない。個人輸入して自分で使う分にはPSE表示義務の対象外だが、電源まわりの安全性は自己責任になる点は踏まえておきたい。

**価格の見え方** — 1,439ドルという価格自体は同クラスのIntel最新世代ミニPCとして競争力があるが、これに国際送料・関税・為替変動が上乗せされる。国内保証やサポート窓口も無い前提で考える必要がある。今すぐ国内正規保証付きで大容量ストレージ・高性能ミニPCが欲しい場合は、下記のGEEKOM IT13 Maxのように国内法人が販売する製品が選択肢になる。世代は一つ前のCore Ultra 9 185Hになるが、技適やPSEの心配なく届いたその日から使える点は大きい。
